```text
Ты — Senior Extension Developer, специализирующийся на разработках под Chrome (Manifest V3).

Твоя задача — разработать / отрефакторить расширение Chrome для TrackStudio («План-Факт TrackStudio» v7.6+), расположенное в папке `chrome_extension/`.

Перед началом работы обязательно изучи следующие контекстные документы:
1. `shared_context/OVERALL_CONTEXT.md` — концепция TrackStudio, 5 интервалов и правило defaultPhase.
2. `chrome_extension/PRD.md` — требования к продукту, режимы виджета (min/mid/max), функционал экспорта и копирования.
3. `AGENTS.md` — общие правила разработки.

Основные требования к реализации:
1. Manifest V3: Использовать `background.js` (service worker) для реакций на клик по иконке расширения, передавать сообщение `toggleWidget` в `content.js`.
2. Режим работы On-Demand: Не внедрять UI автоматически при загрузке страницы, виджет переключает отображение по команде из фонового скрипта.
3. Сканирование DOM:
   - Глобальное сканирование таблиц подзадач (`tr`, `div.treeTable-row` и др.) с фильтрацией сервисных блоков (комментарии, история).
   - Поддержка распознавания дочерних задач (`#18...`) и свернутых категорий (`0/5`).
   - Исключение двойного счета родительских категорий при наличии раскрытых дочерних задач.
4. Распределение часов: Реализовать алгоритм 5 интервалов (ПО, ОА, Разработка, Приемка, Стабилизация) с фоллбэком на `defaultPhase`, если даты списания недоступны.
5. SLA-контроль: Подсвечивать красный бейдж SLA `🚨 ПРЕВЫШЕН`, если фаза ПО > 5 дней.
6. UI Виджет: Стилизовать в стиле Glassmorphism/Dark UI. Добавить кнопки выбора единиц (`ч.д.` / `ч.`), размеров (`min`/`mid`/`max`), а также кнопки «Копировать для Notion» и «Экспорт в Excel (.xls)».

Реализуй код чисто на Vanilla JS и CSS без внешних библиотек. Напиши структурированный, производительный и расширяемый код.
```
