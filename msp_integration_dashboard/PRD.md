# 📄 PRD: Дашборд Интеграции MS Project Server <-> TrackStudio (MSP_Integration_Dashboard.html)

## 1. Назначение Продукта
Специализированный дашборд и инструментарий для синхронизации календарно-сетевых планов из **MS Project Server** с задачами в **TrackStudio**. Позволяет визуализировать данные MSP по конкретному запросу или портфелю запросов, генерировать форматированные плановые ТЗ для TS, экспортировать данные в Excel и автоматически транслировать план в комментарии TS.

---

## 2. Ключевая Функциональность

### 2.1 Импорт и Отображение Данных MS Project Server
- Чтение структуры WBS из MS Project Server (или XML/JSON/Excel выгрузок MSP).
- Отображение вех, плановых трудозатрат по ролям (Аналитик, Разработчик, Тестировщик, Менеджер) и календарных сроков.
- Поддержка как одиночного запроса, так и портфеля взаимосвязанных запросов.

### 2.2 Сопоставление с TrackStudio (MSP <-> TS Alignment)
- Сравнение WBS-этапов MS Project Server со структурой подзадач и статусов в TrackStudio.
- Выявление расхождений в плановых датах вех (например, сдвиг даты сдачи в ОПЭ или окончания разработки).

### 2.3 Генерация и Публикация Плановых ТЗ
- **Копирование в буфер**: Формирование чистого, красиво отформатированного текста плановых ТЗ (с разбивкой по ролям и этапам) для ручной вставки в комментарий TS.
- **Выгрузка в Excel**: Экспорт WBS и плановых показателей в формат `.xlsx` / `.xls`.
- **Авто-публикация в TS**: Автоматическая отправка планового комментария в TrackStudio через API / автоматизационный скрипт под нужным запросом.

---

## 3. Технические Требования

- **Технологический стек**: Python (обработка данных MSP / API TS), HTML5/JS (интерактивный дашборд `MSP_Integration_Dashboard.html`).
- **Форматы обмена**: JSON, XML (MSP Exchange format), REST/SOAP API TrackStudio.
- **Интерфейс**: Табличное представление WBS, визуализация Ганта/вех, кнопки быстрого экспорта и отправки комментариев.
