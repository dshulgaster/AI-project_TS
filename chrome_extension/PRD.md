# 📄 PRD: Chrome Extension «План-Факт TrackStudio» (v7.6+)

## 1. Назначение Продукта
Расширение Chrome (Manifest v3) для оперативного сбора, распределения и визуализации плановых и фактических трудозатрат непосредственно в веб-интерфейсе **TrackStudio** на странице конкретного запроса.

---

## 2. Ключевая Функциональность

### 2.1 Режим работы (On-Demand)
- Расширение **не внедряет UI автоматически** при открытии страницы, чтобы не нагружать браузер.
- Активация происходит по клику на иконку расширения в панели Chrome.

### 2.2 Парсинг данных из TrackStudio DOM
- **Сканирование плановых ТЗ**: Извлечение плановых человеко-дней из заглавных карточек/этапов запроса, комментариев и WBS-оценок (ПО, ОА, Разработка, Приемка, Стабилизация, Управление).
- **Сканирование фактических списаний**:
  - Глобальное сканирование всех строк таблицы подзадач (`tr`, `div.treeTable-row` и т.д.), минуя скрытые таблицы комментариев и истории.
  - Поддержка как раскрытых (дочерних `#18...`), так и свернутых (категорий первого уровня `0/5`) подзадач.
  - **Защита от двойного счета**: если дочерние задачи раскрыты, из вычислений исключается строка-родитель этой категории.

### 2.3 Алгоритм «5 Интервалов» и SLA
- Автоматический поиск дат ключевых операций в истории задачи ($T_{po\_boundary}$, $T_{dev\_start}$, $T_{accept\_start}$, $T_{release}$).
- Распределение списаний по 5 фазам: ПО, ОА, Реализация, Приемка, Стабилизация.
- **SLA-контроль ПО**: Для этапа Предварительного анализа высчитывается потраченное время в днях. Если $> 5$ дней, выводится красный индикатор `🚨 ПРЕВЫШЕН`.

### 2.4 Интерактивный Виджет (UI)
- **Три размера окна**: `min` (компактный), `mid` (стандартный), `max` (развернутый 540px).
- **Переключение единиц**: Человеко-дни (`ч.д.`) или Часы (`ч.`).
- **Быстрые действия**:
  - `📋 Копировать для Notion` — генерация готового Markdown-отчета в буфер обмена.
  - `📊 Экспорт в Excel` — скачивание структурированного `.xls` файла с детальным расщеплением часов.

---

## 3. Технические Требования

- **Платформа**: Google Chrome Extension (Manifest V3).
- **Технологический стек**: Vanilla JavaScript (ES6+), CSS3 (Glassmorphism / Neon Dark UI).
- **Архитектура**:
  - `manifest.json` — конфигурация манифеста V3.
  - `background.js` — сервис-воркер обработчика клика по иконке.
  - `content.js` — изолированный скрипт парсинга DOM и рендеринга виджета.
