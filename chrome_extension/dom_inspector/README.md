# TrackStudio DOM Inspector

Временное диагностическое расширение для проверки HTML-структуры авторизованной страницы TrackStudio.

## Запуск

1. Откройте Chrome и перейдите на `chrome://extensions`.
2. Включите **Developer mode**.
3. Нажмите **Load unpacked**.
4. Выберите каталог `chrome_extension/dom_inspector`.
5. В обычной вкладке Chrome войдите в TrackStudio и откройте задачу `1726097`.
6. Нажмите иконку расширения.
7. Нажмите **Диагностировать AG Grid** и сохраните файл `trackstudio-dom-report-1726097-ag-grid-*.json`.
8. При необходимости вручную раскройте одну категорию и снова нажмите **Диагностировать AG Grid**.

## Состав отчета

Отчет содержит только технические признаки:

- путь страницы и номер задачи из URL;
- количество видимых строк и контейнеров;
- HTML-теги, CSS-классы, роли и имена data-атрибутов;
- глубину строки, если она доступна через `aria-level` или data-атрибут;
- длины текста и флаги шаблонов номера задачи, часов, дат и `0/5`;
- кандидатов на кнопки раскрытия и их `aria-expanded`.
- результаты безопасной проверки кликом: DOM до/после, `aria-controls`, `href`, наличие `onclick`, ближайшая строка и контейнер, а также попытка восстановить исходное состояние.
- контролы, найденные непосредственно внутри строк-кандидатов: теги, CSS-классы, `aria-*`, `data-*`, геометрия и родительский элемент.
- AG Grid-контейнеры, видимые `ag-row`, `ag-cell`, уровни строк, `row-index`, состояния `expanded/contracted` и технические потомки, похожие на контролы дерева.

Названия задач, описания, комментарии и текстовые фрагменты в JSON не сохраняются. Пароли, cookies и сетевые запросы расширение не читает. Панель инспектора использует Shadow DOM, поэтому стили TrackStudio не должны менять читаемость ее текста и кнопок.

## Что передать для следующего этапа

Передайте файл `trackstudio-dom-report-1726097-ag-grid-*.json` или два таких файла до и после ручного раскрытия. Их сравнение покажет структуру AG Grid и реальный контрол дерева.
