# 📄 PRD: Дашборд План-Факт ТЗ по Запросам (PlanFact_Dashboard.html)

## 1. Назначение Продукта
Автономный аналитический дашборд для руководителей и проектных менеджеров, предназначенный для обобщенного контроля плановых и фактических трудозатрат по всему портфелю запросов и проектов на основе ежедневных дампов TrackStudio.

---

## 2. Ключевая Функциональность

### 2.1 Загрузка и Сжатие Данных
- Источник данных: `ts_export.json` (дамп задач, вех, списков подзадач и списаний из TrackStudio).
- Пайплайн обработки (Python):
  - Агрегация и предобработка сотен тысяч строк списаний.
  - Расчет показателей по 5 интервалам для каждого запроса.
  - Сжатие данных для обеспечения высокой скорости рендеринга (60 FPS) в браузере.
  - Генерация единого самодостаточного HTML-файла (`PlanFact_Dashboard.html`).

### 2.2 Фильтрация и Поиск
- **Динамические фильтры**:
  - Заказчик / Банк.
  - Проект / Модуль.
  - Статус / Этап запроса (S1-S6: ПО, ОА, Разработка, Приемка, ОПЭ, Завершен).
  - Ответственный / Менеджер.
  - Статус SLA (В нормативе / Превышен).
  - Поиск по номеру запроса (`#1726097`) или фрагменту названия.

### 2.3 Визуализации и Аналитика
- **Интерактивные диаграммы (Plotly / Vanilla JS)**:
  - Сравнение совокупного Плана и Факта по 5 этапам.
  - Топ-10 запросов с наибольшим перерасходом часов.
  - Анализ соблюдения SLA на этапе Предварительного анализа.
- **Итоговая таблица запросов**:
  - Карточка каждого запроса с детальным сравнением: План vs Факт по ПО, ОА, Коду, Приемке, Стабилизации и Управлению.
  - Цветовая индикация отклонений (зеленый — экономия, желтый/красный — перерасход).

---

## 3. Технические Требования

- **Стек генератора**: Python 3.10+ (pandas, json, jinja2/html generation script).
- **Стек дашборда**: Single File HTML5, Vanilla CSS3 (Dark Mode / Corporate Theme), JavaScript (ES6+), Plotly.js / Chart.js.
- **Автономность**: Файл `PlanFact_Dashboard.html` открывается локально в любом браузере без необходимости запуска собственного веб-сервера.
