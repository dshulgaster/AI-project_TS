# 🤖 AGENTS.md — Правила и Регламенты разработки для AI (Codex / VS Code)

Данный документ содержит обязательные инструкции и стандарты разработки для AI-ассистентов (Codex, GitHub Copilot, Antigravity) в репозитории **Colvir projects**.

---

## 1. Общие Принципы и Правила

1. **Единая Бизнес-Логика**:
   - Любые изменения в алгоритмах калькуляции трудозатрат обязаны соответствовать **Модели 5 Интервалов** (см. `shared_context/OVERALL_CONTEXT.md`).
   - Соблюдать правила защиты от двойного счета (если списания посчитаны по дочерним задачам, родительская категория вычитается).

2. **Чистота Стек и Зависимостей**:
   - **Chrome Extension**: Строго Vanilla JavaScript (ES6+), без сторонних тяжелых библиотек. Соблюдение манифеста Chrome Extension V3.
   - **Дашборды**: Самодостаточные HTML5 файлы. Динамические зависимости (например, Plotly.js) инлайнятся или подключаются автономно.
   - **Python скрипты**: Опираться на `pandas`, `requests`, `jinja2`.

3. **Работа с Секретами**:
   - Никогда не хардкодить логины, пароли, ключи API и токены в коде!
   - Все секреты считываются исключительно из переменных окружения `.env`.

4. **Формат и Качество Кода**:
   - Комментарии в коде на русском языке.
   - Добавлять обработку ошибок (`try-catch` в JS, `try-except` в Python), чтобы сбой парсинга одного элемента не ломал весь интерфейс.

## 2. Структура Репозитория

- `shared_context/` — Документы общего контекста, описание интеграций и бизнес-правил.
- `chrome_extension/` — Исходный код расширения Chrome.
- `plan_fact_dashboard/` — Скрипты генерации и шаблоны дашборда План-Факт.
- `msp_integration_dashboard/` — Скрипты и дашборд интеграции MS Project Server <-> TrackStudio.
